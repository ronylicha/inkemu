## Global Constraints

- `chips` depends on `emu-core` and `thiserror` only, knows no SoC, does no host I/O, builds for `wasm32-unknown-unknown`; `emu-core`, `session` and `boards` build for it too.
- Time is device time, never the host's clock: the DS3231 counts from its configured start by it (3-D9).
- The trace hashes of the X4 and of the reference firmwares do not move: I2C0 without a chip runs the path it ran before (3-D3).
- The session format does not change (3-D12).
- In `host` and `app`, only the catalogue and the ports of the X3 change: SP4 (debugging) works in `host`, `app` and `cpu-rv32` in parallel.
- No third-party binary in the repository or in the CI; CrossPoint is tested locally only.
- Commits `type(scope): description`, no trailer, paths given to `git commit -- <paths>`; nothing pushed. Sources are changed through the editor, never by a script.
- Local checks (`CARGO_BUILD_JOBS=3`): `cargo fmt --all --check`; `cargo clippy --all-targets -- -D warnings` on `emu-core`, `soc-esp32c3`, `chips`, `boards`, `session`, `host`, `emu-cli`; `cargo doc --no-deps` without warning on them; `cargo check --target wasm32-unknown-unknown` on `emu-core`, `chips`, `session`, `boards`; the narrow tests of each task. Left to the CI: `cargo test --workspace`, coverage, `cargo deny`, the `reference-boot` job.

## Rulings

| # | Ruling | Why |
|---|---|---|
| 3-R1 | **Test first, every task**: the failing test is committed with the change that makes it pass; a test names the behaviour. | Repository rule. |
| 3-R2 | **No panic from the bus**: no unchecked indexing or arithmetic on what a firmware sends, in the UC8253 and in the three I2C chips; each has a test that drives a deterministic pseudo-random stream through it. | Spec global §7. |
| 3-R3 | **Every value no source gives** is a parameter of a configuration or an `ASSUMPTION:` in the code, and is listed in spec §7. | The repository's rule on hypotheses. |
| 3-R4 | **The I2C conditions reach a chip at the instant they end on the bus**, computed as I2C0 computed them before SP3; a test asserts the instants a chip is called at. | 3-D3. |
| 3-R5 | **No trace hash moves without a reason written**: the I2C0 path without a chip is unchanged; `tools/reference-firmware` keeps the other projects' pinned hashes; the new reference firmware's trace hash is measured twice before it is pinned. | Consigne. |
| 3-R6 | **The X3 is wired from its profile**, never from code that names it: the catalogue's branch that drew a test pattern for it is removed, and every part of `[wiring]` it uses is checked by the profile loader with an error that names the key. | 3-D10, ADR 0013. |
| 3-R7 | **The glass is one model**: the SSD1677 and the UC8253 share `chips::glass`; the SSD1677's public paths stay (re-exports). | 3-D5. |
| 3-R8 | **The reference firmware checks every value it reads** against the profile in its test, the glass byte by byte, the chips' state after the run, the deep sleep and its wake. | 3-D14. |
